# 广告事件检测与分级确认实施计划

用户已确认上一轮建议。保留 1.0.1 的权限、常驻悬浮窗、单会话控制、持久停止与确认统计修复。

## 设计

无障碍窗口/内容/文字变化事件通知已运行的悬浮服务，在主线程合并调度检测，不使用 startService 拉起服务。定时检测用于补漏。确认任务独立于轮询周期，强证据 120ms、中等证据 300ms 后重新读取窗口。持续事件不能推迟已安排的检查。

将节点读取和规则抽取至 AdDetector：一次有界遍历提取可见节点、父区域、播放器锚点、广告提示、角标位置与结构。自动识别必须有短剧播放器上下文；评论、搜索、会员等区域不提供广告证据。开启报告控件 ID，但不把未经真机验证的 ID 当成唯一依据。倒计时数字不参与广告身份。

AdSkipGate 管理候选、已执行与稳定清除状态。同一包名/窗口内的持续广告只执行一次；未知窗口、短暂空树、切应用不解除已执行锁。观测到播放器中无广告稳定 800ms 后才允许下一广告。强证据和中等证据候选不共享累计时间。保留 700ms 的额外操作保护，替代统一 5 秒等待。

成功统计仍要求同一播放器中广告稳定消失，不能以读取失败或跳转搜索/评论页确认成功。兜底操作必须实时复核广告。运行日志记录事件/候选/指令/确认时间和证据原因，不后台保存截图或界面全文。OCR 不在本阶段。

## 真机采样带来的修正

- 首次全树采样约 1067～1090 节点，扫描 1617～2176ms，不适合快速路径。正式路径改为查询已验证的 `desc`、`cq-`、`b4=` 控件及少量关键词；只对最多 32 节点的小树保留遍历兜底，复杂未知布局返回未知，不回到秒级全树扫描。
- 正片锚点实际为较长“第 N 集 | …”介绍与独立“短剧 · 剧名”，未看到独立“选集”控件。加入双锚点判断及匿名化回归样例。
- 一次真实广告样本显示“退出短剧”控件（b4=）、底部介绍（desc）末尾拼接“广告”，并同时存在“免广告”入口。仅在退出短剧控件与已验证的底部介绍 ID/位置共同成立时接受该后缀；仍排除“不是/没有/免/无/去广告”结尾。
- 定向查询保留命中节点的评论等祖先区域，避免把打开评论面板当作正片恢复。系统输入焦点只有在真正可编辑且聚焦时才参与面板判定。
