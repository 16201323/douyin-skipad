# 跟随系统的 UI 重设计

用户已选择浅色/深色跟随系统。沿用已提出的首页、悬浮窗、设置三页结构，保留所有现有配置与识别/拖动后端。功能扩展单独建议，不自动加入 OCR、云同步、定时任务等。

设计：浅色米白背景、白色卡片、深绿文字与青绿强调；深色使用深灰绿背景与浅青绿强调。原生 View/AppCompat DayNight，无网络字体和额外 UI 框架。20dp 页面留白，16dp 卡片间距，22dp 圆角，至少 48dp 主要交互触摸区。系统栏与主题适配。导航图标使用原生矢量。

首页：产品标题、真实服务状态卡、一键启停、自动跳过开关、今日/本周确认统计、必要权限提醒和使用提示。不能用“已授权”冒充无障碍服务已连接。

悬浮窗：实时 FloatingView 预览、文字/图片切换、裁剪与缩略图、形状、颜色、大小/透明度/字号调节；不要求先启动服务才能编辑。设置：目标应用、权限状态和直达设置、补充检测间隔、版本与主题说明。
