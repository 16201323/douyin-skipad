# 可编辑识别规则、诊断记录与历史版本入口

用户已认可：补齐短剧内直播引流识别，提供可编辑规则与简短本地识别记录；另在合适位置放置 GitHub Releases 列表，支持打开和复制以自行选版本。

实现沿用原生 View/AppCompat、SharedPreferences 与现有检测线程。规则采用有界的完整/包含/倒计时模板/编号角标/结尾匹配，不开放任意正则。每条保存名称、匹配内容、模式、证据类型及启用状态；默认内置规则同样可编辑、删除、关闭，并可恢复全部默认规则。最多24条，每条匹配内容2～60字符。运行时使用一次读取的不可变快照，快速查询和最终判定共用该快照；规则变化需要重新确认，禁止旧候选直接执行。

直播规则需同页可见的已验证退出短剧控件、底部短剧标题、小型左下直播标记和直播入口/结束文案；普通直播、评论和正片对话不提供该组合证据。

本地历史仅保存最多100条时间、应用、规则名称和状态，不保存截图或页面全文。记录状态变化/候选/发送/确认/未确认/失败，不逐次轮询刷盘，可查看、复制和清空。

设置页增加独立规则与记录入口；关于增加 https://github.com/16201323/douyin-skipad/releases 的可选中文本和打开/复制按钮。两个新界面延续浅深主题。
