# GitHub 自动更新与下载网络选择

用户要求自动检查和下载新版本，并要求界面提供更新网络选择。采用自动检查开关及三种下载策略：仅Wi-Fi自动下载（默认）、任意网络自动下载、仅提醒手动下载。手动发起下载可选择本次网络，安装由用户从页面或通知发起，遵循系统授权与确认，不在后台弹出安装界面。

从固定公开 GitHub 仓库 latest Release 获取正式版，不嵌入账号令牌。版本先按数字比较；仅接受固定仓库的指定APK附件、HTTPS、有效大小与SHA256摘要。下载由系统DownloadManager执行并保存任务编号。安装前重新验证摘要、包名、更新版本号、版本名称和与现有应用相同的签名；仅为应用自己的updates目录提供FileProvider读取权限。

打开App时调度检查，同时通过JobScheduler按12小时周期联网检查，失败不阻塞广告识别；系统省电可能延迟任务。默认检查节流6小时，手动检查可绕过。更新设置与任务状态持久化；关闭自动检查取消定时任务，不改变广告开关。下载完成通知进入更新页，不从接收器启动安装器。

新增软件更新页展示当前/最新版本、更新说明、下载状态和进度，以及检查、下载、安装、取消/重试。设置关于中增加入口，保留历史版本打开/复制。
