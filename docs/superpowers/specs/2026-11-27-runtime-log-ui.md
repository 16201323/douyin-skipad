# 运行日志与紧凑界面

用户已批准紧凑界面、完整独立日志页的方案，并明确首页不显示最近日志。不再重复请求布局确认。

首页仅呈现运行状态、两个同级开关及统计，压缩宣传标题和重复准备信息。权限详情使用标题栏返回，设置入口采用统一列表行；保留绿色浅深主题、默认值及用户偏好。

现有识别记录升级为运行日志：本机保存最近300条状态变化，兼容旧数据；分类为信息、问题、成功。未发现广告证据属于信息，不声称程序能够自动知道所有漏识别广告。记录复核取消、检测异常、窗口或规则变化、发送失败和确认结果；请求发送不等于成功。

日志页面仅在可见时自动刷新，按全部/问题/成功筛选；相同状态抑制重复写入，默认展示50条，可加载更多。可展开诊断细节，复制当前筛选日志及当前版本、开关、服务状态。清空须确认；不采集截图、页面全文或媒体标题，不上传日志。

回归覆盖旧日志兼容、保留上限、去重、筛选、复制内容、页面刷新生命周期、导航、默认行为和已有广告误跳保护。本地渲染浅色和深色界面，测试通过后沿用既有自动发布；手机留给用户在线更新。
