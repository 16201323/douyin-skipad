# 设计说明：悬浮窗支持图片内容与自由裁剪

- 日期：2026-11-22
- 状态：已批准，待实施
- 范围：抖音跳广告助手 Android 项目

## 1. 背景与目标

当前悬浮窗仅支持「文字 + 纯色背景」。本次扩展使其支持：

1. 悬浮窗内容可在「文字模式」与「图片模式」间切换。
2. 图片模式下可从系统相册选择图片，经自由框选裁剪后显示。
3. 图片按现有「形状」配置（圆形 / 圆角矩形 / 方形）裁剪显示。
4. 图片可作为背景叠加可选文字（文字清空即纯图片）。
5. 顺带修复此前代码审查发现的全部 8 个问题。

## 2. 非目标

- 不支持拍照（仅相册选取）。
- 不支持动态图（gif）逐帧播放，按静帧处理。
- 不新增形状种类，复用现有形状配置。
- 不引入图片加载库（Glide/Coil），直接用 BitmapFactory 降采样解码。

## 3. 需求确认（用户拍板）

| 项 | 结论 |
|----|------|
| 内容模式 | 图片做背景，文字可选叠加；文字全删即纯图片 |
| 图片来源 | 仅系统相册 |
| 裁剪方式 | 自由框选裁剪后再套形状 |
| 形状来源 | 复用现有「形状」配置 |

## 4. 技术选型

裁剪库：`com.vanniktech:android-image-cropper:4.7.0`（CanHub 维护，uCrop 活跃 fork，Apache 2.0，Maven Central 直拉）。

### 分工策略

| 职责 | 实现方 | 理由 |
|------|--------|------|
| 自由框选 / 缩放 / 旋转（矩形输出） | 库 | 成熟稳定，避免自写裁剪界面引入 bug |
| 圆形 / 圆角矩形 / 方形遮罩显示 | 悬浮窗自绘（BitmapShader + Path） | 与现有形状配置联动，约 20 行，风险低；保证图片与文字模式形状一致 |

库输出矩形裁剪图 → 悬浮窗按当前形状配置画遮罩显示。

## 5. 架构设计

### 5.1 组件

- `FloatingView`（新建）：继承 `View`，`onDraw` 绘制底层形状裁剪图 + 上层可选文字；承载触摸事件。
- `FloatingButtonService`：用 `FloatingView` 替换当前 `Button`，其余服务逻辑不变。
- `ConfigManager`：扩展 `contentMode`、`imagePath`。
- `MainActivity`：新增内容模式 UI 与选图入口。

### 5.2 数据流

```
设置页「选择图片」
  → 库 PickImage（仅相册）
  → 库 CropImageActivity（自由框选 / 缩放 / 旋转）
  → 返回 cropped Uri
  → 降采样解码为 Bitmap → 存 filesDir/cropped.png
  → ConfigManager 存 imagePath + contentMode = 图片
  → 通知 FloatingButtonService 刷新 → 重建 FloatingView 显示图片
```

### 5.3 FloatingView 设计

- 尺寸：正方形，边长 = `buttonSize`（与现有一致）。
- `onDraw`：
  - 若 `imagePath` 有效且 `contentMode = 图片`：加载（缓存）Bitmap，用 `BitmapShader` + 形状 `Path` 绘制底层。
  - 若 `buttonText` 非空：在其上居中绘制文字（颜色、字号取自配置）。
- 触摸事件从 `FloatingButtonService.setupButtonEvents` 迁移：点击跳过、拖动移动、长按切换隐身。逻辑不变。
- 隐身时降低透明度，恢复时还原；**恢复位置需还原**（修 Bug1）。

### 5.4 ConfigManager 扩展

新增键：
- `content_mode`：Int，0 = 文字，1 = 图片，默认 0。
- `image_path`：String?，裁剪后图片私有目录绝对路径，默认 null。

复用现有：`buttonShape`、`buttonSize`、`buttonAlpha`、`buttonText`、`buttonTextSize`、`buttonTextColor`。

修 Bug2：`getEnabledApps()` 区分「未设置」(null) 与「已设置为空」("")，空集应返回空集而非回退默认。

### 5.5 MainActivity UI

设置页新增「内容」区域：
- 单选：文字 / 图片。
- 图片模式：显示「选择图片」按钮 → 启动库裁剪流程；显示当前图片缩略预览；显示「清除图片」按钮。
- 文字编辑框保留（图片模式下作为叠加文字，清空则不显示）。

修 Bug7：`refreshFloatingButton` 在服务未启动时改为先提示用户启动，而非空跑。

## 8. 风险

- 库首次构建需从 Maven Central 下载，依赖网络（此前已能拉取 appcompat，网络可用）。
- `foregroundServiceType` 改 `specialUse` 需在 Manifest 加 `<property>` 说明用途，并兼容 minSdk 24（specialUse 为 Android 14 新增，低版本忽略该属性）。
- 大图解码需降采样防止 OOM。
