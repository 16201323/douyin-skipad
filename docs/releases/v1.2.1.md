# v1.2.1

- 自动跳过可独立运行，无需打开悬浮窗或授予悬浮窗权限；首次未保存配置时默认开启。
- 自动跳过与悬浮窗分别控制，主动暂停会保留至下次打开 App。
- 首页及通知提供暂停/恢复识别；通知另提供显示/隐藏悬浮窗，两个按钮统一柔和配色。
- 缺少悬浮权限时，点击通知中的显示悬浮窗会进入授权引导。
- 保留广告二次确认、去重及暂停时的过期结果保护。

安装包：douyin-skipad-release.apk，版本 1.2.1（versionCode 8），支持 Android 7.0 及以上。

验证：65 项单元回归测试通过；Lint 0 错误、8 警告；发布构建完成并已覆盖安装真机，通知布局已检查。实际广告覆盖率与耗时取决于目标应用版本与页面样本。
