# v1.5.2

- 修复 ColorOS 失焦抖音小窗无法识别的问题：系统的小窗装饰层只有边框可触摸，但外接矩形覆盖整个播放器；旧判断因此错误地将播放器视为完全遮挡。
- Android 11 及以上使用系统提供的真实窗口区域判断可操作范围，保留透明中心；Android 7–10 继续采用矩形判断。
- 跳过按钮也按真实区域检查遮挡，仍禁止点击上层窗口实际覆盖的位置；完全遮挡、锁屏和关闭自动跳过时不发送请求。
- 保留首页独立的自动跳过开关、权限检查、下载网络选择和自动更新。

版本 1.5.2（versionCode 14）。覆盖安装保留原有设置，安装仍需遵循系统提示。

新增回归覆盖透明装饰层下的失焦小窗识别、透明中心点击、实际边框遮挡及不规则目标完全覆盖。缩成系统预览且不暴露应用节点的小窗仍无法读取广告。

验证：115 项完整回归通过，Lint 0 错误、9 警告；真机覆盖安装后已记录抖音小窗 focus=false、eligible=true 并成功选中。该记录采集时是正常短剧，完整广告跳过的现场验证以实施计划为准。
