# v1.5.5

- 将「识别记录」升级为独立的「运行日志」页，入口为设置→运行日志；首页不展示日志。
- 日志页可见时自动刷新，支持全部、问题、成功分类，默认分段显示，可加载更多及展开诊断详情。
- 补充检测异常、发送前复核取消、窗口变化导致确认中止等记录；区分请求已发送与广告消失已确认。
- 复制日志附带复制时的助手/抖音版本、系统版本、开关及服务状态，便于排查。清空日志需要确认，不影响规则和设置。
- 本机滚动保留最近300条状态变化，兼容原有日志；连续状态去重，独立发送和成功事件保留。不采集截图、页面全文或媒体标题，不上传日志。
- 首页压缩标题、状态卡及重复说明，保留同级开关与统计；设置入口采用列表式导航，权限及其他子页统一返回栏。
- 保留浅色、深色、跟随系统主题，以及已有的默认行为和用户偏好。
- 保留抖音、抖音极速版的旧资源ID和文字规则，补查集数/选集锚点，避免介绍栏存在时漏识别旧布局；新增两个包名的旧、新ID及正常内容回归覆盖。

版本1.5.5（versionCode17），沿用原签名与更新来源。131项本地回归通过，Lint无错误，浅色/深色界面渲染检查通过；兼容回归采用节点样本，不代表所有历史版本均经过真机测试。极速版尚缺真机验证；正式安装后的设备表现仍需使用中观察。
