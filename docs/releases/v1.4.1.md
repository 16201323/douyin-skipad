# v1.4.1

- 新增软件更新页面：自动检查 GitHub 正式版，显示版本说明、下载状态和进度。
- 可选择仅 Wi-Fi 自动下载、任意网络自动下载、仅提醒手动下载，默认仅 Wi-Fi；手动下载还能选择本次网络。
- 支持系统后台下载、重新打开后恢复状态、取消与失败重试，下载完成后通知安装。
- 安装前校验 SHA256、大小、包名、版本与签名；安装由用户从页面发起，遵循系统授权和确认，不在后台弹出安装界面。
- 保留原有识别规则、悬浮窗、统计及历史版本入口。

安装包：douyin-skipad-release.apk，版本1.4.1（versionCode 11），支持Android 7.0及以上。更新来源为本项目GitHub Release，覆盖安装保留配置。

验证：88项回归测试通过；Lint 0错误、10警告；浅色/深色更新界面真机检查通过。自动后台任务可能受系统省电限制延迟；安装授权和确认按设备要求处理。
