# v1.3.0

- 新增识别规则管理：内置与自定义规则可增删改、单独开关、恢复默认；保存即应用于快速查询与判定。
- 增加短剧内直播入口、直播结束的组合识别，保留播放器上下文、位置约束及二次确认。
- 新增本地最近识别记录，可查看、复制、清空；仅保留最多100条简短状态与规则名称，不保存截图或页面全文。
- 关于界面加入历史版本与下载入口，支持打开及复制 GitHub Releases 列表，自行选择版本下载。
- 规则变化后重新确认，发送途中旧规则结果不再执行，确认结果保留原命中规则。

安装包：douyin-skipad-release.apk，版本1.3.0（versionCode 9），支持Android 7.0及以上，覆盖安装保留已有配置。

验证：75项单元回归测试通过；Lint 0错误、8警告；发布构建完成，浅色/深色新页面真机检查通过。直播规则已通过模拟节点正反例测试，实际节点可读性与媒体切集响应仍需新的真实广告样本验证。
