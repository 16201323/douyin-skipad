# v1.5.1

- 首页新增明确的「自动跳过」开关，与「显示悬浮窗」独立，保存开关状态；通知中暂停或恢复后，首页自动同步。
- 新增「检查权限」入口；开启自动跳过时检查通知使用权和无障碍授权，缺少授权时引导用户去系统开启。
- 分开显示未授权、无障碍已授权但未连接、后台服务未运行及实际运行状态，避免把开关打开当成已经工作。
- 明确悬浮窗、使用情况访问和 Android 13+ 通知显示的适用范围；自动跳过不要求悬浮窗权限，通知显示授权是可选项。
- 修复打开其他应用小窗后停止识别的问题；支持目标播放器自身作为未获焦点的小窗时继续识别，按实时窗口的包名、可见区域和层级选择唯一目标。
- 完全遮挡或移出屏幕的目标不作为可操作窗口；点击兜底排除被其他窗口遮住的按钮，媒体控制仅发送给选中的目标应用，发送前重新校验窗口标识。
- 自动更新从公开静态 JSON 和 APK 直链下载，无需手机端账号或 API Key；保留下载网络选择及 GitHub 备用来源。
- 下载和安装前核对 SHA256、大小、包名、版本与签名；发布端兼容新旧 Android 签名校验工具的输出格式。
- 新增 GitHub Actions 自动测试、签名构建及发布到下载站，上传后重新下载校验。发布凭据只保存于仓库私密配置，不嵌入 APK。

版本 1.5.1（versionCode 13），支持 Android 7.0 及以上。覆盖安装保留设置，安装仍按系统要求确认。

验证：113 项单元回归通过；发布工具兼容性检查通过；Lint 0 错误、9 警告。同签名验证包在真机地图小窗叠加场景中记录到广告发送与消失确认；失焦目标小窗的模拟回归已通过，真机记录以实施计划为准。
