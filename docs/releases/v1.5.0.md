# v1.5.0

- 自动更新支持公开静态版本文件和 APK 直链，不需要用户登录或客户端 API Key。
- 静态站点优先，GitHub 版本信息作为备用；静态安装包网络下载失败后只尝试一次固定 GitHub 备用地址。
- 保留自动检查、仅 Wi-Fi / 任意网络 / 仅提醒三种下载策略及手动下载的本次网络选择。
- 更新页面显示下载来源，区分连接失败等待重试、等待网络和等待 Wi-Fi。
- 下载后与安装前校验大小、SHA256、包名、版本名称、版本编号和当前应用签名；文件校验不通过不会绕过。
- 安装仍由用户点击发起，遵循系统授权和确认。

版本 1.5.0，versionCode 12。覆盖安装保留设置。静态站点部署地址及真机验证结果记录在本次实施计划中。

验证：97 项单元回归测试通过，Lint 0 错误、9 警告，正式构建及同签名检查通过。发布与手机网络下载实测结果另行记录，单元测试不代表所有网络均可访问。
